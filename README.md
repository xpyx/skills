# skills

Agent skills I write, kept in one place.

A skill is a Markdown file that an AI coding agent loads as instructions — a way
to give an agent a consistent approach to some kind of work, rather than
re-explaining it every session.

## Skills

- **[hands-on](hands-on/)** — the agent scaffolds and writes the tests, you write
  the core logic by hand. For when you want to keep your own judgement sharp
  instead of delegating the interesting part.

## Using them

Point your agent's skill directory at a skill in this repo, or copy the
directory across. Read **[SECURITY.md](SECURITY.md)** first if you plan to track
this repo directly — skill files are executable instructions, not documentation,
and that changes how you should install and review them.
